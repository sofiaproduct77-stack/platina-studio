# PLATINA — студия красоты

Премиальный многостраничный сайт салона красоты: спокойная «холодная» палитра, лендинг в духе Persona, отдельные страницы услуг, команда и портфолио.

## Что внутри

- **Главная** — hero-коллаж, акции, меню услуг, портфолио, команда (стилисты / визажисты / nail), отзывы.
- **Услуги** — 7 направлений (стрижка, окрашивание, укладка, уход, nails, макияж, загар) с прайсом, галереей работ и блоком «Наша команда».
- **Специалисты** — круглые аватарки, запись к мастеру.
- **Запись** — пошаговый wizard (демо без бэкенда).
- **Премиум-слой** — `premium.css`, аккуратная типографика (Cormorant + Manrope).

## Стек

HTML · CSS (modular: `styles`, `home`, `persona`, `premium`, `subpages`) · vanilla JS · Express для статики.

## Запуск

```bash
npm install
npm start
```

Сайт: **http://localhost:3002**

## Структура

| Папка / файл | Назначение |
|--------------|------------|
| `index.html` | Главная |
| `service-*.html` | Страницы услуг |
| `masters.html`, `portfolio.html` | Команда и работы |
| `contact.html` | Онлайн-запись |
| `assets/img/` | Фото услуг, портфолио, специалистов |
| `js/site.js` | Навигация, выпадающее меню услуг, анимации |

## Деплой

Статика + `server.js` — подойдёт любой Node-хостинг или сборка как pure static с другим сервером.
